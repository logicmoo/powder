This independent recovery view remains available when the Prolog application stops. Only the human operator can authorize Copilot actions here.

Use the phrase you entered in the bridge’s own console—not your GitHub password or token. It is sent only to this loopback bridge. The session cookie is HttpOnly and expires after 12 hours.

Teacher and Symbolic agents cannot use this operator session. The bridge uses a dedicated operator.localhost host; do not replace it with the Prolog application’s hostname.
